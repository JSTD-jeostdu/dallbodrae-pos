# 달보드레 카페 POS

특수학급 카페 '달보드레'의 주문·제조·호출을 기기 여러 대로 나눠 처리하는 웹앱입니다.
`index.html` 파일 하나로 동작합니다.

**앱 주소: https://dallbodrae-pos.web.app**

---

## 선생님께

사용법은 **앱 안에 있습니다.** 역할 선택 화면 아래 `처음이신가요? 사용법 보기`를 누르세요.
관리 → 설정의 `사용법 다시 보기`에서도 열립니다.

| 기기 | 역할 |
|---|---|
| 태블릿 1 | 주문 (캐셔 학생) |
| 태블릿 2 | 제조 (바리스타 학생) |
| 모니터 · TV | 호출 (손님이 보는 화면) |
| 선생님 기기 | 관리 (처음 비밀번호 `1234`) |

- 기기마다 주소를 열고 역할을 한 번 고르면 그 기기가 기억합니다.
- 크롬 메뉴의 `홈 화면에 추가`를 누르면 태블릿에 앱 아이콘이 생깁니다.
- 호출 화면은 **시작할 때 화면을 한 번 눌러야** 소리가 납니다.

## 관리자용

### 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체. 화면·로직·설정(`CONFIG`)·자가 테스트가 모두 들어 있다 |
| `logo.png` | 호출 화면 왼쪽 위 로고 (`CONFIG.logoSrc`) |
| `firestore.rules` | Firestore 보안 규칙 |
| `firebase.json` · `.firebaserc` | Firebase Hosting 배포 설정 |
| `달보드레_카페_POS_PRD.md` | 요구사항 |
| `달보드레_카페_POS_구현계획.md` | 태스크별 구현 계획 |

`.md` 문서와 숨김 폴더는 배포되지 않습니다. 인터넷에는 `index.html`과 `logo.png`만 올라갑니다.

### 연습 모드로 띄우기

`CONFIG.firebase.apiKey`를 비우면 **연습 모드**로 동작합니다. 같은 기기의 탭끼리만 데이터가 오가므로
화면 확인과 연습에 씁니다. 파일을 더블클릭해서 열면 스크립트가 돌지 않으니 로컬 서버로 띄웁니다.

```bash
python -m http.server 8777
```

`http://localhost:8777` 을 엽니다. 클로드 데스크톱 앱에서는 `.claude/launch.json`으로 같은 서버를 띄웁니다.

### 클라우드 연결 (현재 설정)

| 항목 | 값 |
|---|---|
| Firebase 프로젝트 | `dallbodrae-pos` (이 앱 전용, Spark 무료 요금제) |
| Firestore 위치 | `asia-northeast3` (서울) |
| 데이터 경로 | `dallbodrae_pos/cafe-2026/…` |
| 상단바 표시 | `연결됨` / 실패하면 `연결 안 됨` + 안내 토스트 |

설정값은 `index.html` 맨 위 `CONFIG.firebase`에 들어 있습니다. 이 값은 비밀번호가 아니라
프로젝트 주소라 공개돼도 됩니다. 실제 접근 범위는 보안 규칙이 정합니다.

**보안 규칙을 바꿀 때**는 `firestore.rules`를 고친 뒤 Firebase 콘솔 → Firestore → `규칙` 탭에
통째로 붙여넣고 `게시`합니다. 이 프로젝트는 이 앱만 쓰므로 기존 내용을 모두 바꿔도 됩니다.

> ⚠️ 로그인 없이 운영합니다. 주소와 설정값을 아는 사람은 `dallbodrae_pos` 경로를 읽고 쓸 수 있습니다.
> 규칙은 이 경로의 정해진 컬렉션만 열고 나머지를 모두 막습니다.
> 관리 화면 비밀번호는 학생 실수를 막는 잠금장치이지 보안 장치가 아닙니다.
> 그래서 학생 이름 말고는 개인정보를 저장하지 않습니다.

### 배포

```bash
firebase deploy --only hosting
```

처음 쓰는 컴퓨터라면 먼저 도구를 설치하고 로그인합니다.

```bash
npm install -g firebase-tools
```

```bash
firebase login
```

첫 화면은 캐시하지 않도록 설정돼 있어서, 배포 후 기기에서 **새로고침만 하면** 새 버전이 뜹니다.

> `firebase.json`의 `ignore`를 고칠 때 주의하세요. `"**/.*"`만으로는 `.git/HEAD` 같은
> 숨김 폴더 **안의** 파일이 걸러지지 않습니다. 그래서 `.git/**`처럼 폴더마다 명시해 두었습니다.
> 배포 로그에 `found 2 files`(`index.html`, `logo.png`)가 아니라 더 큰 숫자가 나오면 멈추고 확인하세요.

### 앱이 멀쩡한지 확인

주소 뒤에 `?selftest=1`을 붙이면 내부 계산 로직을 점검합니다. `PASS n/n`이면 정상입니다.

```
https://dallbodrae-pos.web.app/?selftest=1
```

### 새 학년도에 새로 시작하기

`index.html`의 `CONFIG.spaceId`를 바꿉니다 (예: `cafe-2026` → `cafe-2027`).
이전 데이터와 섞이지 않고 빈 상태로 시작하며, 이전 기록은 그대로 남습니다. 바꾼 뒤 다시 배포합니다.

### 무료 한도

Firestore 무료 한도는 하루 읽기 5만 건, 쓰기 2만 건입니다. 하루 주문 30~50건, 기기 4대 정도면
한도의 몇 %도 쓰지 않습니다. 메뉴 사진을 문서에 직접 넣으므로 메뉴를 20개 넘게 늘릴 때만
콘솔의 `사용량` 탭을 한 번 확인하세요.

### 여러 컴퓨터에서 작업하기

작업을 시작할 때 받고, 마칠 때 올립니다.

```bash

```

```bash

```

새 컴퓨터에서 커밋이 거부되면 사용자 정보를 저장소에 한 번 설정합니다.

```bash
git config user.name "jeodu88" && git config user.email "maseok.t210026@ggm.goe.go.kr"
```

프로젝트 폴더가 OneDrive 안에 있으므로, 두 컴퓨터에서 같은 파일을 만지면
`index.html-DESKTOP-XXXX.html` 같은 충돌 파일이 생길 수 있습니다. `git status`에 낯선 파일이 보이면 먼저 정리하세요.
